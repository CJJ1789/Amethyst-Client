# LegacyXClient
LegacyXClient 是一款主要由ai生成、面向 Minecraft 1.8.9（Legacy Fabric）的客户端增强模组。它在不改动原版玩法逻辑的前提下，提供 Material 3 风格的设置界面、PVP 相关渲染与操作优化、多账号管理、高清字体与原版界面清理，并内置一个更顺手的资源包浏览器。
## 快捷键

| 按键 | 作用 |
|---|---|
| `Right Shift`（右 Shift） | 游戏内打开 / 关闭客户端设置 |
| `Esc` | 关闭设置界面、返回上一级 |
| 鼠标滚轮 / 拖拽 | 设置列表滚动 |
| 自由视角 | 按键可在设置中自行绑定 |

## 功能列表

### 界面与主题
- **仿Material 3 风格设置界面**：卡片式分组、开关、滑块、颜色块、动画过渡，支持亮色 / 暗色主题切换
- **颜色选择器**：预设色板 + HSV 拾色 + 透明度调节
- **准星编辑器**：16×16 像素画布，左键涂色 / 右键擦除，自定义准星贴图
- **原版界面美化接管**：统一按钮与界面风格

### 视角与相机
- **FOV 自定义**：基础 FOV、疾跑、速度药水、缓慢、飞行、拉弓分别设定，可整体关闭动态 FOV
- **自由视角**：按住绑定键自由观察，松开回到原视角
- **动态模糊**：强度可调
- **最小化视角摇晃**：减弱走路时的镜头摆动
- **无受伤镜头抖动**：受击时不再抖动镜头

### 渲染与颜色
- **自定义附魔光效颜色**（Glint）
- **自定义雾**：雾颜色、浓度，可让天空颜色跟随雾色
- **方块高亮**：填充色与描边色独立设置
- **受击颜色自定义**：可修改受伤时的屏幕红色
- **伽马满亮度**（Fullbright）
- **火焰高度调整**：降低第一人称火焰遮挡
- **第一人称手部位置**：前后 / 左右 / 上下三轴微调
- **世界时间覆盖**（仅视觉）：固定到指定时间点
- **天气覆盖**：跟随 / 晴 / 雨 / 雷暴 / 雪，可设置天气是否穿透屋顶
- **高清字体**：内置 Noto Sans HD 字体包，可开关
- **受击残影**：颜色、持续时间、强度、层数可调，可选择是否显示自己的残影
- **格挡/攻击挥动动画**：还原经典手感
- **自定义粒子**：暴击粒子、尖锐粒子倍率可调，可隐藏自身粒子

### HUD 与信息
- **聊天框**：背景色自定义、整体显示开关
- **计分板**：背景色自定义、显示开关、隐藏分数数字
- **自己的名字标签**：背景色与文字颜色可调
- **玩家列表**：列表 HUD 样式接管
- **屏幕模糊 / 暗化**：界面背景虚化与压暗
- **联机玩家标识**：自动识别同客户端玩家并在名字前加徽标

### 操作与输入
- **原始鼠标输入（Raw Input）**：基于 JInput 直连鼠标，绕过系统鼠标加速；可单独设置原始灵敏度，手感更线性
- **自动疾跑**：自动保持疾跑状态
- **无点击延迟**：去掉原版点击判定延迟，连点更跟手

### 资源包浏览器
- **文件夹化管理**：资源包按文件夹分类，支持新建文件夹
- **面包屑导航**：多级目录快速跳转
- **异步索引与图标加载**：包多也不卡列表
- **快速启用**：在列表内直接切换资源包

### 模组列表与更新检查
- **模组列表**：列出当前加载的所有模组与版本
- **更新检查**：对已装模组查询 Modrinth / CurseForge 的可用版本，单独检查 OptiFine 版本
- **运行环境检测**：检查 Java 版本与 Legacy Fabric 版本是否合适，并给出提示

### 多账号管理
- **账号列表**：保存多个账号，点击即可切换，即时应用
- **Microsoft 登录**：设备码流程，浏览器输码授权
- **Skin Site 登录**：填站点地址 + 账号密码获取正版档案
- **AccessToken 导入**：直接粘贴令牌与可选 UUID
- **离线账号**：按离线 UUID 规则生成档案

## 安装

1. 安装 **Minecraft 1.8.9** 与 **Legacy Fabric** 加载器
2. 下载 `LegacyXClient-v1.00.jar`
3. 将 jar 放入游戏目录下的 `mods` 文件夹
4. 启动游戏，进入主菜单即可看到设置入口；游戏内按 `Right Shift` 打开
